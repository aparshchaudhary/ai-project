# Project Archives & Milestone Snapshots 📦

This directory preserves the official uploaded release archives and milestone snapshots for Aura AI:

1. **`aura-2.0-stage0-audit.zip`**:
   - Contains the Stage 0 Comprehensive Audit bundle.
   - Includes baseline system audit documentation, vulnerabilities analysis (`BUG_REPORT.md`), target architecture specifications (`ARCHITECTURE.md`), and the 8-stage upgrade plan (`IMPLEMENTATION_PLAN.md`).

2. **`aura-2.0-stage1-source.zip`**:
   - Contains the Stage 1 Security Hardening bundle.
   - Includes the permission confirmation lifecycle implementation, single-use token verification, replay-attack prevention, and dedicated test suite (`test_stage1_security.py`).
